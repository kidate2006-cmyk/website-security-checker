# Webサイトセキュリティ診断サービス

## 6. 注意事項

本アプリケーションは学習・開発を目的とした
簡易的なWebサイトセキュリティ診断ツールです。

現在の診断対象は example.com に限定しています。

また、HTTPセキュリティヘッダーについては
設定の有無を確認するものであり、
設定値の適切性を完全に評価するものではありません。

## 1. 概要

本アプリケーションは、Webサイトのセキュリティ設定を簡易的に確認するためのWebアプリケーションです。

入力されたURLに対して、SSL/TLS証明書の有効期限やHTTPセキュリティヘッダーの設定状況を確認し、診断結果を画面に表示します。

また、診断結果をPDF形式でダウンロードできる機能や、各セキュリティヘッダーの解説ページも実装しています。

## 2. 使用技術

| 技術 | 用途 |
|---|---|
| Python | 診断処理の実装 |
| Flask | Webアプリケーションの構築 |
| HTML | Webページの構造作成 |
| CSS | Webページのデザイン |
| Requests | WebサイトへのHTTPリクエスト |
| SSL / Socket | SSL/TLS証明書の情報取得 |
| Certifi | SSL証明書の検証 |
| ReportLab | PDF形式の診断レポート作成 |

## 3. 実装した機能

### ① URL入力・HTTPS確認
- 診断対象のURLを入力する機能
- HTTPS通信を使用しているか確認する機能
- 診断対象を許可したホストに制限する機能

### ② SSL/TLS証明書の診断
- SSL/TLS証明書の情報を取得
- 証明書の発行者・所有者を表示
- 証明書の有効期限を確認
- 有効期限までの残り日数を表示

### ③ HTTPセキュリティヘッダーの診断
以下の5項目について、設定の有無を確認します。

- Strict-Transport-Security
- Content-Security-Policy
- X-Content-Type-Options
- X-Frame-Options
- Referrer-Policy

### ④ 診断結果の表示
- 設定されているヘッダー数を集計
- 診断結果に応じた評価を表示
- 未設定の項目を一覧表示
- 各項目について改善アドバイスを表示

### ⑤ 解説ページ
- 5種類のセキュリティヘッダーについて解説
- 設定例や注意点を掲載

### ⑥ PDFレポート出力
- 診断結果をPDF形式でダウンロード
- 診断日時や証明書情報、ヘッダーの設定状況を記録

### ⑦ エラー処理
- URL未入力への対応
- HTTPS以外のURLへの対応
- 診断対象外のURLへの対応
- SSL/TLS通信エラーへの対応
- 接続タイムアウトへの対応
- その他の予期しないエラーへの対応

## 4. 工夫した点

### ① 診断結果を分かりやすく表示
セキュリティヘッダーの設定状況を「設定あり」「未設定」に分類し、色分けして表示することで、利用者が診断結果を直感的に理解できるようにしました。

### ② 改善アドバイスの表示
未設定のセキュリティヘッダーについて、改善アドバイスと解説ページへのリンクを表示することで、診断結果を確認するだけでなく、改善方法も学べるようにしました。

### ③ PDFレポートの作成
診断結果をPDF形式でダウンロードできるようにし、診断内容を保存・共有できるようにしました。

### ④ エラー処理の実装
URLの未入力やHTTPS以外のURL、通信エラーなどに対応し、問題が発生した際に利用者が状況を把握できるようにしました。

### ⑤ 診断対象の制限
診断対象のホストを許可したものに制限し、自動リダイレクトも無効にすることで、意図しないWebサイトへの接続を防ぐようにしました。

## 5. 今後の改善点

### ① セキュリティヘッダーの設定値の評価
現在はセキュリティヘッダーが存在するかどうかを確認しているため、今後は設定値が適切かどうかまで評価できるようにしたいです。

### ② 診断対象の拡張
現在は診断対象のホストを制限しているため、安全な接続先の検証方法を整えたうえで、より多くのWebサイトを診断できるようにしたいです。

### ③ 診断項目の追加
現在の5種類のHTTPセキュリティヘッダーに加えて、Cookieのセキュリティ設定など、ほかのセキュリティ項目も確認できるようにしたいです。

### ④ 診断結果の詳細化
現在の簡易的な評価に加えて、各項目の重要度や具体的な改善方法を表示し、より実用的な診断サービスに発展させたいです。
